About the project

A voice assistant with a memory you can see

JARVIS is a free, open-source AI voice assistant built by Joseph Leung. You talk, it answers out loud, and every exchange becomes a glowing node in a holographic memory graph, linked to everything related you've said before.

What it does

  • TalkSpeak or type. JARVIS answers in a short, spoken reply using Claude, and reads it aloud in your browser's voice.
  • BuildSay a change out loud and Claude Code makes it in a real project folder on your machine, with only file read and edit access.
  • Memory coreMessages are stored in your browser and drawn as a live graph. Search it, click a node to recall it, or purge it all.

Run it in two minutes

You need Node 18+ and Claude Code signed in with a Claude Pro or Max plan. No API key.

  1. Get the code and start the bridge (the small local server that talks to Claude): 
    git clone https://github.com/idontreallyknow-20/jarvis
cd jarvis
node bridge/server.mjs
  2. Open JARVIS in Chrome or Edge, press Space or tap the orb, and talk.
  3. For Build mode, point the bridge at a project: PROJECT_DIR=/path/to/project node bridge/server.mjs

Prefer an API key? Open Settings (⚙), set Talk brain to “Anthropic API key” and paste a key from console.anthropic.com. Talk mode then works without the bridge.

Privacy and safety

  • Your memories, chat history and settings never leave your browser's local storage.
  • The bridge only listens on 127.0.0.1 and only accepts requests from localhost and this site, so other websites can't drive it.
  • Build mode can read and edit files but can't run commands unless you turn that on. Keep your project in git so every change is easy to review.
